# PaperForge LaTeX scaffolds

These files are **starter scaffolds**, not redistributed conference style bundles.

PaperForge deliberately does not vendor changing third-party `.cls`, `.sty`, logo, or author-kit files. Before submission, download the **current official author kit** from the venue link shown in the PaperForge UI and replace/complete the scaffold as required.

Families included:

- ACM — `templates/acm/main.tex`
- IEEE — `templates/ieee/main.tex`
- AAAI — `templates/aaai/main.tex`
- ACL — `templates/acl/main.tex`
- Springer LNCS — `templates/springer/main.tex`
- USENIX — `templates/usenix/main.tex`
- Generic — `templates/generic/main.tex`

The web app's **Export venue-aware .tex** action generates the same kind of scaffold dynamically from the selected conference and paper sections.
